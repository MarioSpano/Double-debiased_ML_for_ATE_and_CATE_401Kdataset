Double-debiased_ML_for_ATE_and_CATE_401Kdataset

The project recreates the easiest application of the DML framework on the 401K dataset, as in "Double/Debiased Machine Learning for Treatment and Structural Parameters" by V. Chernozhukov.
I personally added a CATE estimation on top of Chernozhukov's work just to show one of the many possible additions that one can make after applying this framework.

The implementation of everything is done in the Python code "Code_Seminar_MarioSpanò.ipynb". I personally applied only 2 machine learning models,
but obviously, one can try to implement more. However, I believe that RF is already enough for the purpose of the project. 
Please be alert to the computation time.

The project paper is "Report_Seminar_MarioSpanò.pdf" and the slide set that I used is "ML_final(1).pdf".
The data file is "401k_data.csv".

Enjoy, hope you like my project!
